# Data Structures & Algorithms

Welcome to my personal repo for learning **Data Structures and Algorithms (DSA)**!  
This repository documents my progress, thought process, and solutions to various problems from **LeetCode**, **CodeWars**, and other platforms — using **C** And **JavaScript** to solve them.

---

## About This Repository

This repo serves as my **Solutions and learning process** — it's a place where I:

- Solve problems (as consistently as possible)
- Document the prerequisites for solving the problem
- Write clear **comments** explaining:
  - The problem statement from the platforms
  - How I understood it
  - My **thought process** and **approach**
  - And finally, a link to the **original problem**
